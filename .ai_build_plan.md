# Privacythinkdoc - AI Build Blueprint

This repository contains the documentation site and specialized document viewing modules for the Privacythink ecosystem, built with Vite and React.

## Goal
To provide comprehensive, accessible documentation and secure document rendering components that align with the Privacythink "local-first" philosophy.

## Tech Stack
- **Frontend:** React, Vite, TypeScript.
- **Styling:** Tailwind CSS.
- **Architecture:** Component-driven, optimized for static deployment (\
etlify.toml\ present).

## AI Guidelines
1. Ensure all documentation and viewer components maintain the core "Privacy-First" branding of Privacythink.
2. The UI must be clean, highly readable, and follow the established dark/light mode aesthetics using Tailwind.
3. Keep the \.ai_build_plan.md\ in the repository to provide context for AI-driven updates.
4. When modifying document viewer components (e.g., \ly-toolbar-readonly.tsx\), ensure they handle diverse document formats securely without external API calls.
5. Prioritize build performance and small bundle sizes using Vite's optimization features.
